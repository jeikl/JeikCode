# 内置工具系统

JeikCode 拥有一套高效、经过实战严密验证的原生工具链，涵盖文件读写、代码精准编辑、命令行执行、语义图谱探索以及系统信息检索。

---

## 核心工具一览

| 工具名称 | 功能定位 | 特点与安全性 |
| :--- | :--- | :--- |
| `read` | 读取文件内容、查看图像或展示目录架构树 | 权威名 `read`（兼容 `read_file`）；带行号，支持 offset/limit 分页与 key_string 锚点匹配，单次读取安全可靠 |
| `edit` | 精准局部替换代码片段 | 权威名 `edit`（兼容 `edit_file`）；基于精确字符串匹配，避免重写整文件导致的幻觉丢失 |
| `write` | 全量新建或完全覆写文件 | 权威名 `write`（兼容 `write_file`）；自动递归创建所需父级目录 |
| `glob` | 根据通配符跨目录查找匹配文件路径 | 支持跨平台高效路径模式匹配 |
| `grep` | 正则或字面量搜索文件内容 | 支持上下文行数（context）与文件过滤（glob） |
| `run_command` | 执行本地 Shell 终端命令 | 权威名 `run_command`（兼容 `bash`）；严格超时保护，支持常驻后台任务（返回 PID 与监听端口） |
| `code_explore` | 语义代码图谱与跨文件调用检索 | 结合中英文词林与调用图谱，深度追踪符号定义、读写调用点与业务流转 |
| `todo_write` | 维护结构化多步骤任务清单 | 权威名 `todo_write`（兼容 `todo`）；统一管理开发任务进展并自动合并批处理 |
| `request_user_input` | 主动向用户发起结构化交互提问 | 支持单选、多选与文本输入，用于关键技术选型或获取敏感配置 |
| `jeikcode_config` | 全局与工作区配置管理 | 支持按分类查阅配置指南（`guide`）或在当前会话中即时热重载配置（`reload`） |
| `task` | 派发并行子代理执行独立子任务 | 支持只读探查（`explore`）与限定写入路径范围（`worker`）模式 |

---

## 语义代码图谱与词林检索 (`code_explore`)

在大中型代码库中，单纯使用 `grep` 往往会带来大量无用的同名匹配，造成信息淹没。JeikCode 独创了语义级 CodeIntel 图谱探索：

### 1. 中英文同义词林对齐
JeikCode 内置了双语同义词林扩展。即使你使用中文提问（如“用户鉴权如何校验”），系统也能自动跨语言映射至对应的英文代码符号（如 `AuthClaims`, `verify_token` 等），并自动梳理关键定义点与调用上下游。

### 2. 精确调用链路梳理
通过抽象语法树（AST）解析，`code_explore` 能直接指出：
- 结构体或函数的**唯一定义处**；
- 所有潜在的**读取与写入调用点**；
- 跨模块的**完整调用关系网**。
