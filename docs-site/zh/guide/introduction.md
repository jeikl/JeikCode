# 产品简介

JeikCode 是一款面向专业工程师的全功能、原生高性能开源 **AI Coding Agent**。它基于 Rust 构建核心引擎，不仅具备极致的响应速度与极低的系统资源占用，更打破了传统 AI 助手在单一编辑器或终端内的局限，提供无缝覆盖终端 TUI、现代 WebUI、桌面应用、移动端访问以及后台无头守护进程（Daemon）的完整生态。

::: tip 🚀 敏捷迭代与社区共创愿景
- **极高频迭代与严密代码审批**：JeikCode 始终秉持“开发者驱动”的核心原则。只要社区有真实痛点、提出新功能建议或发起 PR，维护团队都会以极高时效认真 Code Review，并以最快速度完成合入、打包与发布测试验证版本（Beta Channel）。
- **博采众长，持续进化**：JeikCode 深度借鉴与吸纳了业界主流编程 Agent 的工程长处与实战经验，同时在底层架构上彻底重构了性能与工具纪律。
- **拥抱开源，期待与你同行**：我们坚信下一代编程智能体应由开发者共同定义。真诚欢迎全球开发者提交 Issue、贡献代码与插件，共同打磨最纯粹、最强劲的 AI 编码利器！
:::

## 1. JeikCode 是什么？

JeikCode 旨在为专业开发者提供极致轻量、高可控、端到端一体化的智能工程开发体验：

- **⚡ 原生高性能并发底座**：采用 Rust 原生构建，告别庞大的运行环境依赖，秒级冷启动，在高负载会话与大规模代码重构中依然保持毫秒级流畅响应；
- **🌐 全场景交付生态**：打通终端键盘流（TUI）、功能完备的 Web 管理工作台（WebUI）、基于 Tauri 的极简跨平台桌面客户端，以及用于 CI/CD 与服务器常驻的无头服务（Daemon）；
- **🤖 全生命周期智能代理**：从整仓级语义代码理解、架构拓扑追溯、并发原子文件编辑，到多协议模型自适应调度与类 Git 状态机安全回滚，JeikCode 致力于成为开发者的工程级“副驾驶与全栈搭档”。

## 2. JeikCode 与其他 Agent 有何不同？

JeikCode 聚焦于工程落地效率、极致上下文管理、严格工具纪律与全端多场景协同，具备以下核心特性：

### 2.1 语义代码图谱 <Badge type="tip" text="核心技术引擎" />
**原生工具级深度检索，精准定位调用拓扑**

- **主流语言全覆盖**：深度内置 Tree-Sitter 语法解析引擎，原生支持 **Rust、TypeScript、JavaScript、Python、Go、Java、C、C++、C#、Vue、PHP、Ruby** 等 12+ 种主流编程语言；
- **整仓抽象语法树（AST）拓扑网络**：跨文件追踪函数定义、调用拓扑、Trait/Interface 实现与模块依赖，让 Agent 拥有整仓级的“全局上帝视角”；
- **双语词林（Thesaurus）自然语言检索**：JeikCode 深度融合了领域双语词林，**支持直接用日常自然语言或业务语言提问**（如：“订单超时未支付如何自动取消”、“鉴权拦截器在哪里生效”），Agent 结合 `code_explore` 工具多级召回核心实现与上下游链路；
- **极速无感增量更新**：单文件变动仅需 1~3ms 极速差量更新，常驻内存极低，后台无感监听，无需反复手动重建索引。

::: info 💡 词林检索机制
词林检索机制将中英文自然语言概念无缝映射到工程符号网络，实现“想到即搜到”。
:::

---

### 2.2 98–99% 极致缓存 (KV-Cache) <Badge type="tip" text="核心技术护城河" />
**圣地前缀保护，告别缓存雪崩与高昂账单**

- **98–99% 极致 Prompt Caching 命中率**：基于严格的 Append-Only 字节级不可变性设计与圣地地基机制（`sacred_floor`），首部系统提示词与工程规范永久固化；
- **杜绝缓存雪崩 (Cache Thrashing)**：传统 Agent 在多轮交互中频繁改动头部提示词，导致云端 KV Cache 频繁失效、延迟激增与费用暴涨；JeikCode 保证前缀绝对稳定，会话压缩修剪绝不触碰地基；
- **极速首字输出与成本锐降**：近乎全量的缓存命中使首字延迟（TTFT）大幅缩短至毫秒级，同时将高频多轮开发的大模型 API 消耗削减高达 90% 以上。

::: tip 🛡️ 为什么极致缓存是生产力生命线？
对于包含十万行代码与数十轮长会话的复杂项目，只有稳定的 KV Cache 保护才能让高强度重构持续流畅进行，彻底摆脱“越聊越慢、越聊越贵”的困扰。
:::

### 2.3 极简提示词与严苛纪律 <Badge type="tip" text="仅占 9~11k Token" />
**极端克制的上下文占用，全部开源且支持热重载**

- **极端克制的 Token 占用**：JeikCode 秉持极致工程精简理念，拒绝冗余的系统上下文堆叠。**单次交互起手仅占用约 9~11k Token**，将绝大部分宝贵的上下文窗口完整留给代码；
- **严密自洽的系统纪律**：提示词工程兼顾强前沿模型与轻量小模型，确立了并发优先、即错即改、闭环验收的工具纪律，杜绝 Agent 胡乱猜测与破坏性操作；
- **全开源与热重载自定义**：所有提示词资产全面开源，支持在项目级与用户级自由扩展。配置修改无需重启，热重载即刻生效。

### 2.4 跨平台与远程访问编程 <Badge type="info" text="移动端深度适配" />
**全场景覆盖，随时随地移动编程与企业级安全**

- **四端协同无缝流转**：
  - **终端 TUI**：色彩鲜明、支持语法高亮与折叠式实时工具卡片的键盘极客终端；
  - **现代 WebUI**：内置 Git 提交与版本管理、多轮提问历史追溯、多项目多工作区管理与拖拽交互；
  - **桌面客户端**：基于 Tauri 打造，具备轻量体积、原生桌面通知、托盘常驻与系统级集成；
  - **移动端深度适配**：WebUI 针对手机和平板触摸屏进行专门响应式优化，开发者出门在外也能随时随地在手机上审阅代码、指派 Agent 任务、执行编译与提交；
- **安全第一的远程鉴权**：支持通过 Daemon 独立启动并暴露远程访问，服务端强制要求配置访问 Token，杜绝未授权扫描与端口暴露导致的安全隐患。

::: warning 🔒 安全强制防线
绑定非本机回路接口（Non-Loopback）时，服务端底层强制启用 Token 鉴权校验，拒绝无密码公网暴露，守护开发者服务器安全。
:::

### 2.5 极致的工具体系与并发原子保护 <Badge type="warning" text="类 Git 状态机" />
**高并发编辑保护，弱模型与强模型均能稳定执行**

- **工具即核心，杜绝冗余玩具**：JeikCode 的每一个内置工具都是经过实战锤炼的生产级武器；
- **并发原子保护性编辑**：在多文件大范围并发重构时，JeikCode 提供了严密的文件原子性保护机制，彻底避免脏写、写入竞争与代码丢失；
- **类 Git 状态机版本控制**：通过状态机追踪每一轮交互的文件变更。无论是能力强大的前沿模型，还是参数量较小的轻量/弱模型，在编辑和写入代码时都能在严格的状态机防线约束下稳定落地；同时支持随时历史回滚（Undo/Rollback）与变更审查，确保代码库万无一失。
