# 会话与撤销管理

JeikCode 提供持久化会话存储、基于检查点的回退能力与终端快捷键，确保长时间工作可以跨重启延续，也能从走错的回合中干净退出。

---

## 终端快捷键

| 快捷键 | 说明 |
| :--- | :--- |
| <kbd>Enter</kbd> | 发送当前提示词 |
| <kbd>Shift</kbd> + <kbd>Enter</kbd> 或 <kbd>Alt</kbd> + <kbd>Enter</kbd> | 在输入框中换行 |
| <kbd>Ctrl</kbd> + <kbd>C</kbd> | 中断流式生成或取消正在运行的工具 |
| <kbd>Ctrl</kbd> + <kbd>D</kbd> | 输入框为空时退出会话 |
| <kbd>Ctrl</kbd> + <kbd>L</kbd> | 清屏但保留对话上下文 |
| <kbd>Up</kbd> / <kbd>Down</kbd> | 浏览提示词历史 |
| <kbd>Tab</kbd> | 自动补全斜杠命令与文件路径 |

---

## 会话生命周期与管理

### 1. 会话命令

- **`/sessions`**（别名 `/resume`、`/continue`）：打开交互式会话选择器，切换到任意已保存会话（包含消息流、工作目录与模型）；
- **`/new`**：在当前目录开启全新会话；
- **`/rename <名称>`**：重命名当前会话，同步更新选择器与 WebUI 侧边栏；
- **`/cd <路径>`**：切换工作目录并在该目录下开启新会话。

### 2. 自动保存与恢复

每个回合、工具调用与决策都会持久化到本地。崩溃、误退出或重启后，在同一目录再次运行 `jeikcode`（或使用 `/sessions`），即可从最后一次提交的状态继续。

---

## KV Cache 保护机制 (Sacred Floor)

为了最大化利用模型服务商的 Prompt Caching：

- 会话前缀保持 append-only 且字节稳定；
- 环境事实与项目规范（如 `AGENTS.md`）只在会话启动时合并一次；
- 通过 `/remember` 与 `memory.md` 写入的记忆受 `sacred_floor` 保护，上下文压缩时不会被淘汰。

## 撤销、回退与检查点

### 1. 仅回滚对话的 `/undo`

`/undo`（或 `/undo N`）会把对话记忆回退一轮或 N 轮，并把该轮提示词还原到输入框。**它不会修改磁盘上的文件**；需要连代码一起回退时请使用 `/rewind`。

### 2. 终端 `/rewind` 选择器

`/rewind`（或在输入框空闲时双击 <kbd>Esc</kbd>）会打开检查点选择器：

- 按历史回合浏览已保存的快照；
- **当前可用的是对话回溯**；
- 代码回溯会显示为不可用并给出明确原因——每个会话的影子存储尚无有界 GC/配额，贸然启用可能撑爆磁盘。对话回溯不受影响。

### 3. WebUI 可视化回退

WebUI 中每个回答回合卡片都提供回退操作，可把对话与分支状态精确截断到该节点，便于修改提示词后继续推进。代码回溯与终端选择器受同一开关限制（当前不可用）。
